# Formalization of the Classification of Finite Simple Groups

Work in progress.

## Finished Theorems

### (a) The Odd Order Theorem (Feit–Thompson)

Every finite group of odd order is solvable.

### (b) The Strongly Embedded Subgroup Theorem (Bender–Suzuki)

If $X$ is a finite simple group containing a strongly embedded subgroup, then $X \cong L_2(2^n)$, ${}^2B_2(2^{n/2})$, or $U_3(2^n)$ for some $n\ge 2$.
